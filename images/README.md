# 실제 동물 사진

다음 JPG 파일을 이 폴더에 넣으면 자동으로 표시됩니다. script.js에 경로가 이미 연결되어 있습니다.

| 동물 | 파일 이름 |
|---|---|
| 개구리 | frog.jpg |
| 붕어 | fish.jpg |
| 나비 | butterfly.jpg |
| 참새 | sparrow.jpg |
| 토끼 | rabbit.jpg |
| 강아지 | dog.jpg |
| 민물거북 | turtle.jpg |
| 다 자란 잠자리 | dragonfly.jpg |
| 고래 | whale.jpg |
| 다람쥐 | squirrel.jpg |

파일명은 소문자와 .jpg 확장자까지 일치해야 합니다. 몸 전체와 다리·날개·지느러미가 잘 보이는 사진을 넣어 주세요. 사진이 없거나 불러오지 못하면 이모지로 표시됩니다. 다른 이름이나 PNG를 사용하려면 script.js에서 해당 동물의 image 경로를 바꾸세요.

관찰 화면의 사진을 클릭·터치하면 확대 창이 열립니다. 닫기 버튼, 창 밖 클릭, Esc 키로 돌아올 수 있습니다. 도감에는 같은 사진의 작은 썸네일이 표시됩니다.
