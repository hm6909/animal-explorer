# 🐾 동물 분류 탐험대

초등학교 3학년 과학 수업용 정적 웹앱입니다. HTML, CSS, JavaScript만 사용하며 외부 라이브러리나 서버가 필요하지 않습니다.

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. 인터넷 연결 없이도 사용할 수 있습니다.

## 파일 역할

- `index.html`: 한국어 페이지, 화면 영역, CSS와 JavaScript 연결
- `style.css`: 숲속 테마, 큰 글씨와 터치 버튼, 반응형 화면, 짧은 반짝이 효과
- `script.js`: 동물 데이터 배열, 단계별 문제, 복수 선택 채점, 점수, 도감과 결과 화면
- `images/`: 실제 동물 사진을 넣는 폴더

## 수업 진행과 점수

탐험 안내 → 관찰 → 특징 찾기 → 생활 장소 또는 이동 방법 분류 → 설명 및 도감 등록을 10마리에게 반복합니다.

관찰 완료 10점, 특징 문제 10점, 분류 문제 10점으로 동물당 30점, 총 300점입니다. 각 단계에서 최초 완료 시 한 번만 점수를 줍니다. 오답 뒤 정답을 골라도 10점을 받으며 감점하지 않습니다. 따라서 끝까지 탐험한 학생은 모두 300점과 별 3개를 받을 수 있습니다. 250점 이상 별 3개, 200점 이상 별 2개, 그 아래 별 1개 기준이 코드에 구현되어 있습니다.

도감은 탐험 중에도 열 수 있고, 등록된 카드를 누르면 설명을 다시 봅니다. 새로고침하면 탐험 기록은 초기화됩니다.

## 동물 데이터 수정과 이미지 교체

`script.js`의 `animals` 배열을 수정합니다. `features`는 `featureOptions`의 문구와 정확히 일치해야 합니다. `type`은 `habitat` 또는 `movement`이며 정답은 각각 `habitatOptions`, `movementOptions`의 `value`와 일치해야 합니다. 동물을 추가하면 진행률과 도감 카드 수도 자동으로 늘어납니다.

각 동물의 JPG 경로가 이미 연결되어 있습니다. `images/README.md`에 안내된 파일 이름으로 사진을 넣으면 됩니다. 예: `images/frog.jpg`. 다른 이미지 파일을 쓰려면 해당 동물의 `image` 값을 상대 경로로 수정하세요. 빈 경로나 로드 실패 시 이모지를 표시합니다.

잠자리 전용 표준 이모지가 없어 곤충 이모지와 안내 문구를 사용합니다. 수업 전 잠자리 PNG를 넣으면 실제 몸의 특징을 관찰하기 좋습니다. 거북이는 민물거북, 잠자리는 다 자란 잠자리를 기준으로 합니다. 서식 장소와 이동 방법을 기준으로 묶는 활동이며 생물학적 분류군을 묻는 활동은 아닙니다.

## GitHub Pages 배포

1. GitHub 저장소에 이 프로젝트 파일과 `images` 폴더를 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택하고 `main` 브랜치의 **/(root)**를 저장합니다.
4. 배포가 끝나면 표시되는 웹 주소로 접속합니다.

모든 자원은 상대 경로로 연결되어 저장소 이름이 붙는 GitHub Pages 주소에서도 실행됩니다.

## 확인할 항목

- 특징은 복수 선택이며 정확한 조합이어야 다음으로 진행합니다.
- 오답 안내 후 다시 선택할 수 있고 점수는 줄지 않습니다.
- 10마리 완료 시 점수 300점, 발견 10마리, 별 3개가 나옵니다.
- 도감 왕복으로 중복 점수를 얻지 않습니다.
- 다시 탐험하기는 점수와 도감을 초기화합니다.
- 키보드 Tab과 Enter/Space로 선택하고 화면을 이동할 수 있습니다.


## 추가된 탐험 활동

- 관찰 화면의 동물은 약 1.6배 커졌으며 동물별 `observationHints` 질문 3개를 보여줍니다. 이모지에는 작은 다리나 비늘이 생략될 수 있으므로 실제 관찰 수업에서는 PNG 사진을 넣어 주세요.
- 상단 지도는 2마리마다 다음 지점으로 이동합니다. 지도는 탐험 여정을 나타내며 동물의 실제 서식지를 뜻하지 않습니다.
- 분류 단계의 동물 카드를 PC에서 상자로 드래그하거나, 모든 기기에서 상자를 클릭·터치하여 분류할 수 있습니다.
- 정답 설명 → 도감 등록 → 발견 화면 → 다음 탐험 순으로 진행합니다.
- 반짝이는 1.6초, 오답 흔들림은 0.35초만 표시됩니다. 기기의 움직임 줄이기 설정을 지원합니다.
- 도감 수집 진행률과 물음표에서 동물로 바뀌는 효과를 추가했습니다.
- 3마리 발견 시 관찰왕, 6마리 발견 시 동물박사, 10마리 발견 시 생태탐험가 배지를 받습니다. 새 배지 알림은 약 3초 표시됩니다.
- 기존 점수·결과·다시 탐험 기능은 유지됩니다. 새로고침 시 기록은 초기화됩니다.


## 실제 사진 관찰 및 확대

10마리의 사진 경로를 `images/frog.jpg`부터 `images/squirrel.jpg`까지 연결했습니다. 사진 파일 자체는 사용자가 추가합니다. 사진은 `object-fit: contain`으로 비율을 유지하고 몸 전체가 잘리지 않게 표시합니다. 관찰 힌트는 사진 아래에 있습니다.

PC에서는 사진 위에 마우스를 올리면 살짝 확대되고, 사진 클릭이나 태블릿 터치로 큰 관찰 창을 열 수 있습니다. 닫기 버튼·창 밖 클릭·Esc로 닫으며 기존 탐험 진행과 점수는 유지됩니다. 도감도 같은 실제 사진을 썸네일로 사용합니다. 지도, 배지, 버튼과 장식의 이모지는 그대로 유지합니다.


## 한 화면에서 활동하기

PC와 넓은 태블릿에서는 사진과 활동을 좌우로 배치하고 상단 여백을 줄였습니다. 좁은 스마트폰이나 글씨를 확대한 화면에서는 내용을 자르지 않고 세로로 배치합니다.


시작·안내·정답 설명·발견·도감·상세 카드·결과 화면도 여백과 배치를 조정했습니다. PC와 태블릿에서는 사진과 설명을 나란히 배치하며, 좁은 휴대폰에서는 단계에 따라 사진 높이를 줄입니다. 페이지 내용을 잘라 숨기는 방식은 사용하지 않으며, 아주 작은 화면이나 큰 글씨 확대 설정에서는 필요한 스크롤이 유지됩니다.
